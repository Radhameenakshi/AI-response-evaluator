# 🤖 AI Response Evaluator

A responsive web application that allows users to compare two AI-generated responses using structured human evaluation criteria. The application provides an intuitive interface for rating responses across multiple dimensions, automatically calculates scores, determines the better-performing response, and stores evaluation history using Local Storage.

---

## 📌 Features

* Compare two AI-generated responses side by side
* Evaluate responses using multiple quality criteria:

  * Accuracy
  * Clarity
  * Completeness
  * Relevance
  * Creativity
* Interactive 5-star rating system
* Automatic score calculation
* Winner determination
* Reset evaluation with a single click
* Local Storage support for saving evaluation history
* Responsive and modern user interface
  ---

## 📖 How It Works

1. Enter the original prompt.
2. Paste two AI-generated responses.
3. Rate each response across five evaluation criteria.
4. Click **Evaluate Responses**.
5. View the calculated scores and winner.
6. Evaluation results are saved locally in the browser.
